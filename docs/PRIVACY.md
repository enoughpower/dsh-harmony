# 隐私政策（口袋工作台 / DSH Harmony）

- 更新日期：2026-09-20
- 生效日期：2026-09-20
- 适用应用：口袋工作台（包名 `com.dsh.lite`）

## 一、引言

本应用是 DeepSeek Harness（DSH）的 HarmonyOS 客户端，用于让你在手机上连接并访问**运行在你自己电脑上的** DSH 服务（经你自行安装的 dsh-pocket 插件）。我们非常重视你的隐私，本政策说明本应用如何处理信息。

## 二、我们收集与使用的信息

本应用**不收集、不上传**你的个人信息，不包含第三方统计或广告 SDK。

- **连接地址**：你扫码或手动输入的电脑端服务地址（如 `http://192.168.1.5:3081`），仅保存在**设备本地**，用于连接历史与自动连接。
- **相册图片**：仅当你主动选择图片并发送到会话时，图片在**设备本地**读取后直接发送至**你自己电脑上的** DSH 服务，不经过任何开发者服务器。
- **网页数据**：应用内 WebView（ArkWeb）的 Cookie / 缓存仅用于维持你与电脑端服务的会话，可在「设置」中一键清除。
- **剪贴板**：仅在你点击「复制 / 复制全部」时写入内容。
- **日志**：仅产生设备本地调试日志，不自动上传。

本应用**不会**读取你的通讯录、定位、短信、通话记录、应用列表等信息。

## 三、设备权限说明

本应用声明的系统权限如下（与提交应用市场审核的安装包完全一致）：

| 权限 | 类型 | 用途 | 触发时机 |
| --- | --- | --- | --- |
| `ohos.permission.INTERNET` | normal（普通权限） | 访问你指定的电脑端服务（局域网或你配置的公网隧道） | 使用期间 |
| `ohos.permission.GET_NETWORK_INFO` | normal（普通权限） | 感知网络变化，自动在局域网直连与公网隧道间切换 | 使用期间 |
| `ohos.permission.CAMERA` | **user_grant（用户授权）** | **仅用于扫描连接二维码**（ScanKit） | 点击「扫码连接」时申请；拒绝后仍可手动输入地址 |

说明：

- 除上述 3 项外，本应用**不申请任何其他权限**（不包含存储 / 下载目录、通讯录、定位、麦克风等权限）。
- 相机权限仅在前台使用，不会在后台调用摄像头。

## 四、第三方服务

- 你所连接的 DSH / dsh-pocket 服务运行在**你自己的电脑**上，相关数据的处理由你自行控制。
- 应用市场分发的版本**不包含推送（Push Kit）功能**，也不会申请通知权限。
- 电脑端可选的余额查询由**你的电脑**自行发起（读取你本机的 API Key），本应用仅从你的电脑读取结果，不接触任何 API Key，也不向第三方上传数据。

## 五、数据存储与安全

- 本应用仅在设备本地保存连接地址等配置信息；PIN / 凭证不落盘。
- 你可在「设置」中随时清空连接历史与 Web 数据。

## 六、未成年人

本应用为面向开发者的技术工具，不面向未成年人单独提供服务。
